## Adversarial retrieval, structural invariants, and frontier reasoning

**Retrieval tools are now active attack targets.** You can adversarially craft web content to influence retrieval-grounded AI systems. A single blog post is sufficient to corrupt AI-generated summaries on a topic. For agent builders using web retrieval or RAG, this is a distinct attack class — not prompt injection, but adversarial tool output. See [Tool Use](../concepts/tool-use.md) for more.

**Type-system enforcement outlasts prompt instructions.** Last week's Forge finding showed that runtime harness guardrails dramatically raise coding agent reliability. Structural backpressure goes further: encoding invariants as sealed types with constrained constructors makes them structurally impossible to violate rather than conventionally wrong. A constraint in a type is reviewable and permanent; a prompt rule decays as context accumulates. The tradeoff is the same as Forge — the human still encodes the invariants upfront — but they stay enforced. See [Agentic Loop](../concepts/agentic-loop.md) for more.

**Extended reasoning at frontier scale is qualitatively different.** An OpenAI reasoning model disproved the Erdős unit distance conjecture — open for 79 years — with a summarized chain of thought running to 125 pages. The key move imported algebraic number theory into a combinatorial geometry problem, a form of cross-domain breadth individual specialists rarely have. This was a general-purpose model, not a purpose-built math system, which distinguishes it from earlier specialized AI math work. See [Planning](../concepts/planning.md) and [Evaluation](../concepts/evaluation.md) for more.
