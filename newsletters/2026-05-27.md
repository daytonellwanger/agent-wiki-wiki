## CLAUDE.local.md: a personal-patterns layer for Claude Code

A machine-local, gitignored companion to CLAUDE.md. The pattern: dump recurring PR feedback into it immediately after code reviews, then prune once the habits stick. This captures personal patterns without polluting the shared project config — the natural complement to keeping CLAUDE.md short. The two files target different audiences: CLAUDE.md is for the team, CLAUDE.local.md is for you on this machine.

See [Claude Code](../tools/claude-code.md).
