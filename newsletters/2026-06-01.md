## Output Styles: distributable behavioral plugins for Claude Code

Claude Code now has a built-in plugin system called Output Styles that lets operators encode behavioral modes at the session level, injecting additional instructions via the `SessionStart` hook. This generalizes a pattern teams have been implementing manually via CLAUDE.md: rather than each project maintaining its own behavioral constraint file, an operator can publish a plugin that encodes a mode — teach, guide, review-only, explain-before-implementing — and distribute it.

The built-in Learning style is the clearest example: the agent inserts `TODO(human)` markers at decision points, asks users to implement meaningful code segments themselves, and adds educational callouts explaining implementation choices. It was initially restricted to Claude for Education users before being opened broadly.

The practical implication for agent builders: behavioral modes that previously required per-project CLAUDE.md customization can now be packaged, versioned, and shared as plugins. See [Claude Code → Output Styles](../tools/claude-code.md) for details.
